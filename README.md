# 考研英语核心词 V1

基于 FSRS 间隔重复算法的考研英语二词汇学习系统，内置 2010-2026 年真题阅读例句，支持 Excel 批量导入生词。

## 在线使用

https://sogood-one.github.io/kaoyan-core-vocab/

## 功能特性

### 学习系统
- **FSRS 间隔重复算法**：根据回忆率(R)、稳定性(S)、难度(D)动态调整复习间隔
- **四遍学习法**：每个新词以随机方向(英选汉/汉选英)学习4遍，加深记忆
- **强制复习**：每日学习前必须复习前一天新学的单词（北京时间5:00为日期分界线）
- **自主复习**：按遗忘程度排序，优先复习最可能遗忘的单词
- **错题本**：答错3次以上的单词自动进入错题本，集中突破
- **答错重测**：答题错误后延迟3-5个单词自动重新测试

### 词库管理
- **内置词库**：1521+ 考研核心词汇
- **Excel 批量导入**：支持 xlsx/xls/csv 格式，自动识别多种列格式
- **自动去重**：导入时检测重复词汇，出现≥3次标记为高频词
- **高频词标记**：复习时橙色徽标提醒，重点记忆
- **自动同步**：Excel 导入的新词自动同步到 GitHub 系统词库
- **进度备份**：支持导出/导入学习进度（含自定义词汇）

### 真题例句
- **真题来源**：2010-2026 年考研英语二阅读理解原文
- **智能匹配**：新导入单词自动匹配真题例句
- **答题后展示**：选择答案后显示真题例句 + 完整中文翻译
- **关键词高亮**：例句中目标单词自动高亮

### 用户体验
- **多用户支持**：每个用户独立进度，数据保存在本地
- **学习计时**：实时显示本次/今日/累计学习时长
- **中断恢复**：关闭浏览器后可继续未完成的学习会话
- **连续打卡**：记录连续学习天数
- **键盘快捷键**：1234/ABCD 选择答案，Enter 继续，Esc 退出
- **发音功能**：Web Speech API 美音发音 + 有道词典在线 TTS 备用
- **移动端适配**：响应式设计，手机浏览器完美支持

## FSRS 算法

核心公式：

```
回忆率：R = (1 + t / (9S))^(-1)
下次间隔：I = 9 × S × (1/目标回忆率 - 1)
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 目标回忆率 | 90% | 复习时希望达到的记忆概率 |
| 最大间隔 | 365 天 | 防止间隔过长 |
| 初始稳定性 | 1.0 天 | 新词首次学习后的记忆稳定性 |
| 初始难度 | 5.5 | 中性难度（范围 1-10） |
| 掌握阈值 | 30 天 | 稳定性超过30天标记为已掌握 |

**答对**：稳定性增长 `S *= 1 + 1.5 × (1-R) × (10-D)/10`
**答错**：稳定性衰减 `S *= 0.4 + 0.1 × D/10`
